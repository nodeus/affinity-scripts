# Affinity Scripts

Release builds of custom scripts for Affinity by Canva. Each folder holds the ready-to-run script plus its README.

## Scripts

| Script | Description | Version |
|--------|-------------|---------|
| [chart-builder](https://github.com/nodeus/affinity-scripts/tree/main/chart-builder) | Build line, bar and donut diagrams from text-frame data directly in Affinity | 1.5.1 |
| [color-palette-gen](https://github.com/nodeus/affinity-scripts/tree/main/color-palette-gen) | Extract fills, strokes, gradients into organized swatches with RGB, CMYK, HSL, HEX values | 9.2.0 |
| [hanging-chars](https://github.com/nodeus/affinity-scripts/tree/main/hanging-chars) | Fix orphaned characters and prepositions with non-breaking spaces (RU/EN) | 1.0.0 |

## Usage

1. Open the script folder, copy the `.js` file content.
2. In Affinity: run it via automation / Script Manager, or save to the script library.
3. See each folder's README for data format and parameters.
